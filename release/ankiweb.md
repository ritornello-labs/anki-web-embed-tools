Turn a URL in an Anki note into a resizable embedded web view.

## See it in Anki

### Create an embed from a URL

![Type and select a Wikipedia URL, choose Create Embed from URL, and see the page load inside the note field](https://ritornello.dev/media/ankiweb/2026-10-07-v7/web-embed-tools/create.gif)

Select a raw URL or right-click an existing link, then choose **Create Embed from URL**. The selected URL is replaced by an embedded web page inside the note.

### Resize its width and height

![Use four width and two height toolbar actions while the complete iframe stays visible inside the editor field](https://ritornello.dev/media/ankiweb/2026-10-07-v7/web-embed-tools/resize.gif)

Use **W− / W+** and **H− / H+** for quick adjustments, or **Size…** for exact dimensions. The example reduces the embed from 1058 × 480 to 738 × 360 pixels, with the full frame visible throughout. The toolbar also lets you add space above or below the embed, or remove it.

These actions work in the regular note editor and Browser editor.

## New in 0.2.1

Selected URLs now become embeds inside modern Anki's editable note fields, so the embedded page saves correctly with the note.

Requires Anki 25.09 or newer. Embedded URLs are stored in note HTML and may sync with your collection. Some sites block iframe embedding.
