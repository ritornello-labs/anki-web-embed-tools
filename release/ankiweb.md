# Web Embed Tools

Turn a URL in an Anki note into a resizable embedded web view.

Select a raw URL or right-click an existing link, choose **Create Embed from
URL**, then use the editor toolbar to resize, reposition, or remove it. The
same workflow works in both the regular note editor and the Browser editor.

Requires Anki 25.09 or newer. Embedded URLs are saved in the note HTML and may
sync with your collection; use only sites you trust. Some sites block iframe
embedding, which is expected.

GitHub: [https://github.com/elvis-sik/anki-web-embed-tools](https://github.com/elvis-sik/anki-web-embed-tools)
