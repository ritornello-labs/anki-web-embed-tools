## Web Embed Tools 0.2.0

First public release of Web Embed Tools for Anki 25.09 and newer.

- Convert selected URLs and existing links into resizable embedded web views.
- Edit embeds in both the regular note editor and the Browser editor.
- Keep the saved note HTML portable, with controls for exact sizing, spacing,
  and removal.

Some sites intentionally block iframe embedding; that is expected.
