Turn a URL in an Anki note into a resizable embedded web view.

## See it in Anki

![Resize a loaded Wikipedia page using Web Embed Tools in Anki’s editor](https://ritornello.dev/media/ankiweb/2026-10-07-v7/web-embed-tools/resize.gif)

Select a raw URL or right-click an existing link, choose **Create Embed from URL**, then use the editor toolbar to resize, reposition, or remove the embedded page. This works in the regular note editor and Browser editor. The demo resizes a loaded Wikipedia page using the actual editor toolbar.

Requires Anki 25.09 or newer. Embedded URLs are stored in note HTML and may sync with your collection. Some sites block iframe embedding.
